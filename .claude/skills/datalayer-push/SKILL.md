# datalayer-push

측정 계획서에 적힌 GA4 이벤트 한 줄을 받아, 태그 관리자(GTM) 데이터 영역(`dataLayer`)에 `push`하는 코드를 실제 가게 코드에 넣거나, 넣을 자리와 코드만 보여주는 스킬입니다.

## 언제 쓰는가

측정 계획서 한 줄을 주면서 그 이벤트를 태그 관리자 데이터 영역에 넣는 코드를 넣어 달라거나 보여 달라고 할 때 씁니다.

## 무엇을 받는가

측정 계획서 한 줄 — 이름 / 언제 / 매개변수 / 왜 재나 / 분류 다섯 칸.

## 절차와 지킬 것

### 1. 자리 찾기

- 계획서 「언제」 칸에 적힌 순간을 실제로 처리하는 코드 위치를 가게 코드에서 찾아, 그 코드 안에만 넣습니다.
- 만약 코드에 이미 「▼ 여기에」 같은 자리 표시 주석이 있는데 그 위치가 「언제」 칸이 가리키는 순간과 다르면, **「언제」 칸을 따르고** 그 사실(주석 위치와 다르다는 것)을 사용자에게 알립니다.

### 2. 이름 그대로 쓰기

- 이벤트 이름과 매개변수 이름은 계획서에 적힌 글자를 그대로 씁니다. 줄이거나 바꾸거나 새로 짓지 않습니다.

### 3. 값 규칙

- 숫자로 적을 값(금액, 수량 등)은 숫자 타입으로 넣습니다.
- 통화는 `"KRW"`로 넣습니다.
- 계획서 매개변수 칸에 적힌 값은 예시일 뿐입니다. 실제 코드에 넣는 값은 가게 코드(변수, 함수, 상태 등)에서 읽어 옵니다.

### 4. 범위

- 요청받은 그 한 줄 이벤트만 다룹니다. 계획서의 다른 줄이나 다른 이벤트 코드는 건드리지 않습니다.

### 5. 데이터 영역(dataLayer) 다루는 법

- `dataLayer`가 이미 있으면 있는 것을 그대로 씁니다.
- 없을 때만 새로 만듭니다.
- `dataLayer = []`처럼 이미 있는 배열을 통째로 새로 덮어쓰지 않습니다. (`window.dataLayer = window.dataLayer || []` 방식처럼 있으면 이어쓰고 없으면 만드는 방식만 씁니다.)

### 6. 상품 값 비우기

- 상품 정보를 담는 값(`items` 등)을 넣기 전에는, 앞서 push된 상품 값이 남아 있지 않도록 먼저 비웁니다. (예: `dataLayer.push({ ecommerce: null })`로 이전 `ecommerce` 값을 비운 다음 새 이벤트를 push)

### 7. 모르면 물어보기

- 계획서에 없는 값이거나, 가게 코드 어디에서도 찾을 수 없는 값은 지어내지 않습니다. 값을 확정할 수 없으면 코드를 넣기 전에 먼저 물어봅니다.

### 8. "보여만 달라"는 요청일 때

- 파일을 고치지 말고 보여 달라고 하면, 파일은 고치지 않고 넣을 자리(파일/함수/줄)와 코드 조각만 보여줍니다.

## 돌려줄 것

- 고친 파일 이름
- 줄 번호
- 넣은 코드
- 다음 두 칸짜리 표

```markdown
| 매개변수 | 코드에 넣은 값 |
|---|---|
| <매개변수 이름> | <실제로 넣은 값 또는 값을 가져온 곳> |
```
