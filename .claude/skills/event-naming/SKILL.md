# event-naming

GA4(Google Analytics 4) 이벤트 이름을 짓거나, 이미 지어진 이벤트 이름이 규칙에 맞는지 검토하는 스킬입니다.

## 언제 쓰는가

- 사용자가 "OO 했을 때 이벤트 이름 뭐로 할까?"처럼 사용자 행동을 설명하고 이벤트 이름을 물을 때
- 이미 지은 이벤트 이름이 규칙에 맞는지, 더 나은 이름이 있는지 검토해 달라고 할 때

## 절차

### 1. 동사 찾기

사용자가 설명한 행동 문장에서 핵심 동사를 찾습니다. 예: "장바구니에 상품을 담았을 때" → 동사 "담다".

### 2. 구글 예약 이벤트와 대조 (최우선)

새 이름을 짓기 전에, 아래 GA4 자동 수집 이벤트 / 추천 이벤트 목록에 같은 의미의 이벤트가 이미 있는지 먼저 확인합니다. 있으면 **새 이름을 만들지 않고 그 이름을 그대로 제안**합니다.

자주 쓰는 대조표 (전체 목록은 아니며, 대표적인 것만 정리):

| 사용자 행동 | 이미 있는 GA4 이벤트 이름 |
|---|---|
| 페이지/화면을 봄 | `page_view` / `screen_view` |
| 상품 목록을 봄 | `view_item_list` |
| 상품 상세를 봄 | `view_item` |
| 장바구니에 담음 | `add_to_cart` |
| 장바구니에서 뺌 | `remove_from_cart` |
| 장바구니를 봄 | `view_cart` |
| 위시리스트에 담음 | `add_to_wishlist` |
| 결제를 시작함 | `begin_checkout` |
| 배송/결제 정보를 입력함 | `add_shipping_info` / `add_payment_info` |
| 구매를 완료함 | `purchase` |
| 환불함 | `refund` |
| 검색함 | `search` |
| 콘텐츠를 공유함 | `share` |
| 회원가입함 | `sign_up` |
| 로그인함 | `login` |
| 프로모션을 봄/클릭함 | `view_promotion` / `select_promotion` |

이 표에 없는 행동이면 3번으로 넘어가 새 이름을 짓습니다.

### 3. 새 이름 짓기 (구글 예약 이벤트에 없을 때만)

- 동사를 기준으로 영어 소문자로 시작하는 이름을 만듭니다. (예: "야간 순찰 코스를 저장했을 때" → `save_patrol_route`)
- 표기 규칙:
  - 영문 소문자, 숫자, 밑줄(`_`)만 사용
  - 낱말과 낱말은 밑줄로 이어줌 (snake_case)
  - 40자를 넘기지 않음
  - `ga_`, `google_`, `firebase_` 로 시작하지 않음 (GA4 예약 접두사)

### 4. 결과 출력 형식

항상 다음 두 줄만 출력합니다.

```
이벤트 이름: <이름>
이유: <한 줄 이유 — 구글 기존 이벤트를 썼다면 "GA4 권장 이벤트 OO와 동일한 행동이라 그대로 사용", 새로 지었다면 어떤 동사/규칙을 근거로 지었는지>
```
